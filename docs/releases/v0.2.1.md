# LearnHarness Server v0.2.1

Selected fixes and reading improvements from upstream LearnHarness 0.6.1. No data format or configuration changes; upgrade by rebuilding the image.

## Fixes

- Compaction no longer overwrites skips, question dismissals, direction changes and pause state saved while the summary was running. The compaction marker is inserted where the summarized chat ended, and later messages are kept.
- Typing in answer and thinking fields during lessons no longer re-renders the whole session.
- Flashcards generation no longer fails on OpenCode Go with `MissingSessionID`: plugin worker requests forward the host session id.
- Over-escaped code blocks in tool content are recovered. Normal code and mixed or incomplete fences are left unchanged ([policy](../tool-content-recovery.md)).

## Reading

- Graph cards and expanded Chains statements render Markdown, LaTeX and code. Proposition-name chips and source/folder labels in Chains stay plain text.
- Inline code in graph cards and Chains statements matches the size and color of the surrounding text.
- Graph cards are repositioned when their rendered content changes size.
- Wide tables wrap to the available column where possible instead of being cut off.

## Not taken from upstream 0.6.1

- Graph snapshot source-map reads: this project already reads the map once per snapshot.
- llama.cpp nested context metadata: custom providers are declared in the config file, not discovered.
- Nix profile directories for Claude Code discovery: the CLI is pinned in the image.

Thanks to the upstream contributors credited in the [LearnHarness 0.6.1 release](https://github.com/amosblomqvist/learnharness/releases/tag/v0.6.1).
