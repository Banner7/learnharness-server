# LearnHarness Server v0.1.1

Cleanup release. No new features and no data format changes; upgrade by rebuilding the image.

- Removed code, assets and scripts left over from the desktop app, in-app key entry and subscription sign-in (connection dialogs, file-drop and folder-path helpers, request-cause tracking, the ChatGPT logo, `dev-fresh.sh`, the image-runtime smoke, the OAuth probe and its trace includes).
- Removed `LH_IGNORE_ENV_KEYS`; it only served the removed key-entry first run.
- Dropped 11 unused npm dependencies, including `jose`.
- One glob compiler for agent file tools and the vault skip list. Agent `find`/`grep` patterns now treat `**/` as whole folders, so `src/x.ts` no longer matches `foosrc/x.ts`.
- One vault note hash and one full-mask string instead of duplicates.
- Comments, docs and the bug template describe the server deployment, not the desktop app.
- Tests that pinned removed behavior or source text were removed.
