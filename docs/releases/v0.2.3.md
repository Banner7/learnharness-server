# LearnHarness Server v0.2.3

Selected fixes from upstream LearnHarness 0.7.0, plus dependency security updates. No new UI and no data format change. Upgrade by rebuilding the image.

## Security and dependencies

- Next.js 16.4.3 → 16.4.6 (the November 2026 Next.js advisories are fixed from 16.4.5).
- Pi libraries (`@earendil-works/pi-ai`, `pi-agent-core`) 1.4.0 → 1.5.2.
- `npm audit fix` within the existing ranges (undici, zod, DOMPurify, puppeteer-core / chromium-bidi, fast-uri, source-map-js, Hono). `npm audit --omit=dev` now reports 0 vulnerabilities (10 before: 5 high, 4 moderate, 1 low).

## Agent and provider fixes

- Claude Code: a worker keeps its parked CLI process between tool rounds instead of losing it, and a late Claude error can no longer revive a retired run.
- Background agents (research, plugin workers, Flashcards) no longer stop at an implicit turn cap.
- Flashcards uses the provider's own output limit.
- One-shot plugin calls carry their own routing id (never a reused Claude Code process).
- Direct Anthropic requests keep full replay, because the per-request credential is not part of Pi's thread fingerprint.
- Side chat pairs an answer with the question call that came before it, not the last reuse of the same call id.
- Claude Fable is in the Claude Code model list (`fable`).

## Teaching

- Probing gives more weight to the learner's reasoning and uses it to decide what to ask next; confidence is calibrated across answer modes. Obsolete wait instructions are removed from the blocking question tools. Prompt text only.

## Rendering and performance

- Plan maps size boxes from labels laid out in the reading font, cap labels at the reading size, re-measure on font changes, and reuse the layout when a session snapshot has not changed.
- Long transcripts: older turns use `content-visibility`, the newest learner turn stays fully laid out, and session stats refreshes no longer download the transcript.
- Copying TeX from display equations works again. Graph labels no longer split emoji or flags. The Stop button stays on the activity card's face.
- Drawing Pad: fewer repaints while drawing, erasing on a stationary eraser, ink rebuilt after a lost canvas context, long code blocks captured in full, and Undo / Clear no longer flicker during a stroke. Our touch tool sizes are kept.
- Rich code blocks: common TeX preamble omissions are healed and compile errors show diagnostics.

## Not taken from upstream 0.7.0

- Sidebar session folders and the graph folder filter; transcript width setting and side-by-side question layout; option letters on single-select questions; the per-segment prompt editor (UI changes, not approved).
- PDF figure crop and annotation (not chosen).
- Manual model catalog refresh from `pi.dev`; desktop startup announcements and update IPC; OpenCode Go side-chat routing; custom-endpoint model discovery (upstream's custom-endpoint module is not in this project).

## Verified

Fixed during the port: 8 `session-identity` expectations brought in line with Pi 1.5.2, and a plan-block width expectation set to our 17 px default reading size. Flashcards (205), Drawing Pad (105) and Rich code blocks (27) plugin tests pass; production build passes. Not checked in a browser or on the phone.
